# Curso Online — Controles Ambientais Aplicados à Indústria em Goiás

Projeto de marketing para divulgação do curso online da Recurso Sustentável.

## Estrutura

```
02-curso-controles-ambientais/
├── 01-briefing/          → Briefing e informações base do curso
├── 02-estrategia-divulgacao/ → Plano de marketing e cronograma
├── 03-conteudos/         → Peças de divulgação por status
│   ├── em-elaboracao/
│   ├── para-aprovacao/
│   ├── aprovados/
│   └── reprovados/
├── 04-materiais-visuais/ → Referências e assets visuais
└── 05-metricas/          → Acompanhamento de resultados
```

## Fluxo de conteúdo

1. **Em elaboração** — equipe produzindo
2. **Para aprovação** — enviado para Cinthia/Higor validarem
3. **Aprovado** — pronto para publicar
4. **Reprovado** — devolvido com feedback

## Nomenclatura de arquivos

Padrão: `YYYY-MM-DD_plataforma_tema.md`

Exemplo: `2026-06-01_instagram_carrossel-fiscalizacao-go.md`

# Recurso Sustentável (Equipe)

Repositório de conhecimento compartilhado para a equipe de marketing do Recurso Sustentável.

## Como usar

1. Clone este repositório
2. Abra a pasta com o Claude Code
3. Faça perguntas sobre o projeto — o Claude tem acesso a todo o contexto

## Estrutura

| Pasta | Conteúdo |
|-------|----------|
| `01-cliente/` | Briefing, cronograma, reuniões |
| `02-marca/` | Identidade visual, paleta, referências |
| `03-conteudo/` | Posts e artigos por plataforma e status |
| `04-fluxo-de-trabalho/` | Processos e responsabilidades |
| `05-anotacoes/` | Notas gerais |

## Fluxo de trabalho

```
Em elaboração → Para aprovação → Aprovado → Publicado
                                → Reprovado (volta com feedback)
```

## Contribuindo

- Siga a nomenclatura: `YYYY-MM-DD_tema-do-post.md`
- Mova os arquivos entre pastas conforme o status muda
- Registre reuniões usando o template em `01-cliente/reunioes/_template.md`

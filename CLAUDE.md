# Recurso Sustentável — Base de Conhecimento (Marketing)

## Sobre o projeto

Este repositório é a base de conhecimento compartilhada da equipe de marketing para o cliente **Recurso Sustentável**. O foco é a produção de conteúdo para redes sociais.

Qualquer membro da equipe pode consultar este repositório usando o Claude para obter contexto sobre o projeto, histórico de decisões, e status dos conteúdos.

## Estrutura do repositório

- `01-cliente/` — Briefing, cronograma e atas de reunião
- `02-marca/` — Paleta de cores, direção de arte, referências visuais
- `03-conteudo/` — Conteúdos organizados por plataforma e status (em elaboração, para aprovação, aprovados, reprovados)
- `04-fluxo-de-trabalho/` — Processo de produção e responsáveis
- `05-anotacoes/` — Notas gerais da equipe

## Fluxo de conteúdo

Cada conteúdo passa pelas etapas:
1. **Em elaboração** — equipe está produzindo
2. **Para aprovação** — enviado ao cliente para validação
3. **Aprovado** — pronto para publicar
4. **Reprovado** — devolvido com feedback (ver comentários no arquivo)

## Nomenclatura de arquivos de conteúdo

Usar o padrão: `YYYY-MM-DD_tema-do-post.md`

Exemplo: `2026-05-20_sustentabilidade-empresarial.md`

## Tom de voz

- Informativo e engajante
- Autoridade em sustentabilidade e meio ambiente
- Linguagem acessível sem ser superficial
- Foco em educar o público sobre práticas sustentáveis e soluções ambientais

## Diretrizes para o Claude

- Ao responder perguntas sobre o projeto, consulte primeiro o briefing em `01-cliente/briefing.md`
- Para questões de estilo visual, consulte `02-marca/direcao-de-arte.md`
- Para saber o status de um conteúdo, navegue as pastas em `03-conteudo/`
- Respeite o tom de voz definido acima ao sugerir ou revisar textos
